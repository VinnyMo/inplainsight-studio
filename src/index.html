InPlainSight Studio

Encrypt or recover a file

Create an encrypted PNG, WAV or FLAC, or recover the original file with its password.

01

Choose your source file

Any regular file
02

Choose output format

Format details and planned budgets

Planned output budgets, not current capacity — default / advanced: PNG 100 / 500 MB; JPEG 25 / 100 MB; WAV and FLAC 1 / 4 GB; video 5 / 50 GB. Decimal units. These targets do not enable formats or increase current limits.

03

Set a strong password

Use a password manager or several randomly chosen words. There is no password reset.

Leave blank to use the default name. PNG extension is added automatically.

You’ll choose where to save next.
Existing files are never overwritten.

!

Keep the encrypted file exactly as saved

Keep the exported file unchanged so it can be recovered. Audio exports contain noise; avoid high playback volume. This app never plays audio. Share it as a file attachment and keep a backup. This experimental prototype has not been independently audited; don’t rely on it for irreplaceable or high-risk data.

Encryption protects the contents, not the fact that a file is hidden.
