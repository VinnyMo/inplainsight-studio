Keep the PNG exactly as saved

Resizing, editing, screenshots, or image compression can destroy the hidden file. Share it as a file attachment and keep a backup. This experimental prototype has not been independently audited; don’t rely on it for irreplaceable or high-risk data.

Encryption protects the contents, not the fact that a file is hidden.
